# Python Basics for AI Research

A collection of Python programming examples designed to practice essential concepts used in machine learning and AI research.

## Project Overview

This repository contains 10 Python examples covering fundamental programming concepts, data processing, and basic machine learning evaluation.

The goal is to build a foundation for implementing and analyzing AI experiments.

## Contents

| File | Topic | Description |
|---|---|---|
| `01_variables.py` | Variables | Variables, data types, and formatted strings |
| `02_lists.py` | Lists | List operations and accuracy statistics |
| `03_dictionaries.py` | Dictionaries | Storing and tracking experiment results |
| `04_conditions.py` | Conditions | Model evaluation using conditional statements |
| `05_loops.py` | Loops | Iteration and experiment analysis |
| `06_functions.py` | Functions | Reusable functions for accuracy analysis |
| `07_sorting.py` | Sorting | Ranking machine learning models |
| `08_comprehensions.py` | Comprehensions | Data filtering and transformation |
| `09_exceptions.py` | Exception Handling | Input validation and error handling |
| `10_accuracy.py` | Model Evaluation | Calculating and comparing classification accuracy |

## Technologies

- Python 3
- Git
- GitHub

All examples use Python's standard library without requiring external packages.

## How to Run

Clone the repository:

```bash
git clone https://github.com/m2nx6/20262RCOSE32202.git
cd 20262RCOSE32202
```

Run an example:

```bash
python3 01_variables.py
```

Replace the filename to run other examples.
